# Studi Kasus
## Penyedia reselling produk
Harmon Corp. adalah perusahaan alas kaki yang menjual produknya secara daring dan luring. Selain memproduksi sendiri, perusahaan bekerja sama dengan rekanan dan menjual ulang produk lain, didukung strategi iklan dan pemasaran untuk memperluas jangkauan pasar. Untuk mendukung pertumbuhan bisnis, Harmon Corp. membuka program kemitraan yang menjual hasil produksinya. Program ini mampu memperluas pasar tanpa biaya operasional tambahan yang besar dan meningkatkan volume penjualan. Oleh karena itu, diperlukan sistem berbasis data untuk mendukung registrasi dan verifikasi mitra, mengintegrasikan proses pemesanan dari reseller ke perusahaan, mencatat laporan harian penjualan, serta mengelola stok secara efisien.
